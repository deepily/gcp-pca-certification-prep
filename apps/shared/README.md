# Shared Resources for Markdown-to-Slides Conversion

This directory contains common resources used across all conversion approach implementations.

## Directory Structure

```
shared/
├── input/          # Source markdown files for testing
├── templates/      # Shared templates and themes
└── README.md       # This file
```

## Input Files

- `gcp-cert-prep-slides-v2.md` - GCP Cloud Architect certification presentation with 15 slides
- Use this file to test all conversion approaches for consistent comparison

## Templates

Common themes and templates will be stored here for consistent branding across all conversion methods.

## Usage

Each conversion project should reference files in this shared directory to ensure consistent testing and comparison of output quality.
